## 0. 一句话

把抽取网（LLM 从会话原文捞候选事实）在**历史日志上离线跑一遍**，用阶段一的标签量它：
像不像我（第 0 档）、有没有用（下游命运）、新候选准不准（残差人标）。
**回放不是上线**：候选只进影子库与报告，绝不碰活库；语义改动只出提案。

## 1. 已定决策

### D1：输入口径只有一份

抽取网的 transcript 输入**复用 replay.js 的过滤与切窗**（source.kind='user'、
按 turn/start 切窗、逐帧解码），不许第二份实现。注入过滤判据改动必须同时移动
SCAN_RULES 与 rulesDigest。间接回声（464 条插件注入影响了用户下一句）修不了，
**写进每份报告的结论边界**，不许假装干净。

### D2：匹配池 = cutoff 快照，时间泄漏是硬伤

候选的一切匹配（查重、残差全库匹配）只对 `snapshotAt(store, 会话 cutoff)` 做。
**测试必须证明**：cutoff 之后写入的行不可能被命中（构造一条未来行，断言匹配不到）。
relaxed 约束的"生效"语义由消费侧按 relaxedAt 滤（快照重建的是存在且活跃）。

### D3：治理走引擎真函数，影子库隔离

候选过治理链用**引擎的 similarity / isSameClaim / 查重判据**，不许重写一把尺子。
ADD 候选落**影子库**（活库的副本，回放专用路径），绝不写活库。
撞上近似旧条目只出 supersedes 提案（照同根因提示的形状），不自动归档。
状态三分类：`noop`（查重命中）/ `add`（全新）/ `proposal`（冲突待提案）。

### D4：两层评估，判据钉死

| 层 | 算什么 | 禁什么 |
|---|---|---|
| 有标签（15 会话） | 召回 = 被候选复现的标签 / 分母；复现判据 = 治理级匹配（查重命中该标签行），不是逐字相等 | 样本小且偏（开发期自觉写入），**不得当发布数** |
| 无标签（216 会话） | 候选量、NOOP 率、新候选率、残差精确率（人标）、下游价值加权 | **禁算召回**（83% 轮数没有分母） |

- 召回分母 = 非 slot ∧ 本库 = **334（待用户 approve；approve 后钉进 SCAN_RULES）**。
  双口径照报（仅 tool vs tool+钩子）。跨库 1 条单列。
- NOOP 率对照**人写基线 ≈ 0**（414 次调用 0 查重）——不是对照"今天的正则"。
- 残差（治理匹配后剩下的新候选）导出**人标文件**：should-record / shouldn't，
  用户标，精确率 = should-record / 已标残差。模型不得自标。
- 下游价值加权（第 1 档）：命中的标签按后续命运加权（revised/derivedBy/transfer
  = 有用，hits=0 且 unused 归档 = 死重）。报告注明幸存者偏差。

### D5：可比较性，表头钉死一切

每份回放产出表头必含：`promptVersion / modelId / temperature / seed /
engineGit / scannerVersion / rulesDigest / codeDigest / generatedAt / storePath`。
**表头不一致的两份回放不得比较分数**。prompt 文本本身进工件（或哈希 + 存档路径），
改一个字就是新版本。

### D6：成本与降级照 llm-summary 模式

并发 1、单会话调用预算上限、单次超时、失败降级留痕（不静默跳过会话）。
离线脚本，零热路径影响。模型路由显式配置或可发现，路由进表头。

### D7：报告必带的三段边界

1. 选样偏差：有标签层 = 6.5% 会话 / 17% 轮次，且是最不代表的开发期会话。
2. 间接回声：464 条插件注入污染了"用户下一句"的独立性，不可修。
3. 第 0 档只证"像不像我"；"更好"要等第 3 档（配对探针 + 人金标），不在本阶段。

## 2. 审查清单（判据先于代码）

**A 输入与口径**
- [ ] 过滤/切窗/解码 import 自 replay.js，grep 不得出现第二份实现
- [ ] 注入排除可复现：回放输入里 0 条非 user 消息（抽查断言）

**B 快照与泄漏**
- [ ] 匹配只走 snapshotAt；时间泄漏测试在（未来行命中不了）
- [ ] cutoff 继承自基线工件（hook 行修复后全行有 cutoff）

**C 治理与隔离**
- [ ] 查重/极性用引擎函数（import，非重写）
- [ ] 活库零写入：grep 无活库 storePath 的写路径；影子库路径独立
- [ ] supersedes 只出提案；noop/add/proposal 三分类有测试

**D 指标**
- [ ] 召回只在有标签层算；无标签层算召回的代码路径不存在（测试断言）
- [ ] 分母 334（approve 后）/ 双口径 / 跨库单列
- [ ] NOOP 率对照人写 ≈ 0 写在报告里
- [ ] 残差人标文件导出，模型自标路径不存在
- [ ] 下游加权有幸存者偏差注明

**E 表头与可比较**
- [ ] 表头十字段齐全（D5）；prompt 文本或哈希 + 存档在
- [ ] 改 prompt/模型/温度任一 → 表头变 → 报告拒绝与旧表头比较

**F 成本与红线**
- [ ] 并发 1 / 预算 / 超时 / 降级留痕有测试
- [ ] 零热路径影响（独立脚本，不挂 pre-step）
- [ ] 报告带 D7 三段边界，缺一不过

**判决**：任一不过 → critique 带测量打回；全过 → pass 报告，用户 approve。
回放产出是**实验报告不是基线**——基线只有阶段一工件；第 3 档探针另立规格。
