# 判据 v1.3（草案）：措辞归一 —— 什么叫"同一个决定"

v1.2 定义了"同一命题 = 主语 + 类型 + 断言"。全量把这个定义撞出一个洞：

**#5 的候选是 requirement（"人格页要与记忆海形成对立"），标签是 fact（"人格页视觉定案：太极两半"），
金标却是同一命题。** 类型门在这里必然误杀，因为类型说的是**措辞**，不是**决定**。

同一句话可以说成要求，也可以说成定案：

- "面板要与星空形成对立"（要求措辞）
- "面板定案为深空星图"（定案措辞）
- 两者指的是**同一个设计决定**。

所以断言层要做的事只有一件：**把措辞剥掉，还原成"决定"再比。**

## 决定 = 对象 + 属性 + 取值

| 层 | 含义 | 例子 |
|---|---|---|
| 对象 | 这个决定是关于什么产品/功能/人的 | 面板 / 记忆库 / 取名 / 协作方式 |
| 属性 | 决定的维度 | 视觉风格 / 帧率 / 名字 / 分层 |
| 取值 | 定下来的那个值 | 深空星图 / 必须有保障 / "余" / 四层 |

两个短语是同一个决定，当且仅当三元组（对象、属性、取值）相同或一方包含另一方。

## 措辞归一的三条规则（草案，待样本外验）

1. **情态剥离**：去掉 `要与 / 必须 / 应有 / 要有 / 须有 / 不得 / 禁止 / 别再` 这类道义词，
   剩下的部分才是取值内容。
2. **定案识别**：`定案 / 已定 / 最终定为 / 采用 / 选定了` 后面的部分是取值；
   `定案` 类句子与 `要求` 类句子**在决定层同一**，只是措辞不同。
3. **比较型评价归一**：`A 比 B 更适合 X` → 决定为（对象=X，属性=选型，取值=A）。

## 与类型门的关系（不是替代）

- 类型门拦"同话题不同事实"（#2 特质≠要求、#6 原则≠定义、#9 偏好≠配置、#10 策略≠目标），
  这部分实测 rejectPrecision 0.80，保留。
- 断言层补"不同类型同一决定"（#5 这类措辞错位）。
- **两层串联**：先过类型门（能拦的拦掉），剩下的用决定三元组再比一次；
  类型门误杀 #5 这种，要由断言层在门**之后**捞回来，而不是把门放宽。

## 边界：仍不追 1.0

- #8（愿景两侧面：自主生活 vs 内在倾向欲求）留给断言层判"断言是否同一"，
  **不靠堆主语规则**；若三元组也判不出，就记为已知错配。
- `contradicts`（一条要、一条不要）单独标，不混进 `pairSame`。

## 五处承重缺口（写代码前必须指定，2026-11-19 补）

### 1. 三元组怎么确定性抽（最承重）

中文无句法分析，所以**不假装做句法分析**，只做两件确定性的字面活：

- **属性词表**：由判据维护一张**封闭**的属性表。
  **词表必须从全量错误谱原则化生成**（按"这是哪个维度的决定"归并），不许对着个案抄词 ——
  type-rules 那轮抄词的代价已经付过一次（类型准头涨、门判跌）。
  词表要报**覆盖率**：抽不出属性的比例就是降级占比，它本身是一个读数，不是内部实现细节。
  命中表里的词 → 属性。
- **取值串**：句子中**属性词之后**的连续片段（到句读或虚词为止），规范化（去空白、去"的/了/一种/那种"）。
  命中不了属性词 → 属性 = `unknown`。

抽不出三元组就**降级到"归一取值串的实体重合"**（沿用 entity-v2 的实体重合，但只在归一后的取值串上比），
并在产物里标 `degraded: true`。**降级路径的准确率单独报，不与三元组路径混算。**

### 2. "一方包含另一方"要精确

必须是 **对象同 ∧ 属性同 ∧ 取值包含**。
**不许**裸串包含（那会把"深空星图面板"与"面板"判成同一个决定，重新引入话题级过配——
正是 v1.2 已经判死的错配形态）。

### 3. 情态剥离必须保否定极性

剥掉 `不得 / 禁止 / 别再 / 不要` 之后，被否定的东西要记成 **¬X**，不是 X。
`不要半透明` → 取值 = ¬半透明；`采用纯星图` → 取值 = 纯星图。这两条**不是同一个决定**。
这与引擎 `isSameClaim` 的极性守卫是同一条纪律（那边按"整句有无否定词"判，这边按取值极性判，
两边结论要一致，不一致以更严的一边为准）。

### 4. 校准数据必须来自人审池

断言层的正例（同决定不同措辞）在 gold-20 里只有 #5 一条，n=1 没法校准。
序列固定：**人审池 42 条人标 → 从中挑"同决定不同措辞"案例 → 对着案例定规则 → gold-20 校准 → 样本外验。**

### 5. 比较型归一限定子类

只有 `A 比 B 更适合 X`（**选型类比较**）才归一成"决定：选型=A"。
`帧率 59 仍觉得卡` 这类是**评价**，不是决定，不许强转。


## 断言规则草案（对着 12 条双标正例设计，2026-11-19）

12 条正例全部落在同一种形状上：**候选与标签说着同一个决定，但措辞的命题类型不同**。
其中 8 条候选是 fact（把决定说成陈述），4 条候选是 requirement/preference（说成要求或偏好）。
所以规则要做的不是"识别类型"，而是**把类型剥掉**。

### 规则 A：情态剥离
去掉 `要与 / 必须 / 应有 / 要有 / 须有 / 应当 / 需要在` → 剩下的当取值。
（#8「轴注册表归人格层，引擎只带 choice」↔「轴注册表归人格层…这条我认账：引擎不 import 轴表」）

### 规则 B：定案/陈述互认
`定案 / 已定 / 最终定为 / 采用 / 选定 / 已否决` 后面的部分当取值；
陈述句里的"归 X / 只保留 Y"同样当取值。
（#1「半透明已否决」↔「明确拒绝半透明」；#22「想要有自己的生活」↔「最终形态：属于自己的生活」）

### 规则 C：极性 ¬X
`否决 / 不再 / 不要 / 拒绝 / 去掉` 的出现把取值翻成 ¬X。
（#1 的 ¬半透明；这条与引擎 isSameClaim 同纪律）

### 规则 D：三元组同一性
对象同 ∧ 属性同 ∧ 取值相同或包含（**不是裸串包含**）→ 同一决定。
（#14「记忆与人格缺一不可」↔「两者都有才是灵魂」）

### 规则 E：可复用性前置（防把过程当决定）
候选若是"我做了什么/第一版如何"的过程记录，或指代空洞（"方案三""那件事"）→ 不进配对，
按 v1.1 直接判不该记。本池里 #2/#10/#25/#35 落在这一条。

### 属性维度（原则化，不从个案抄词）

按"决定的维度"归成 10 个维度，词表按维度归类而不是收录原句：
**归属 / 关系 / 底线与口径 / 顺序与推进 / 方式与排障 / 风格与形态 / 存留与位置 / 命名 / 选型 / 结论与实验**。
抽不出维度 → 降级到归一取值串的实体重合，标 `degraded: true`，覆盖率单独报。

### 12 条正例的覆盖预期（待实测）

按上面的规则，12 条里 A+B+C 能覆盖 6 条（#1/#8/#15/#16/#17/#22 这类"情态/定案"差），
D 覆盖 3 条（#14/#26/#27），#11/#23/#24 依赖属性维度是否命中（顺序/结论/存留）。
**这是纸面预期，不是结论** —— 实现后要在 12 条上报覆盖率与降级占比。

## 校准纪律（沿用）

- 判据先于代码；词条不许从 gold-20 里抄（type-rules 那轮已付出代价：类型准头涨、门判跌）。
- 断言层规则先在全量错误谱上设计，再在 gold-20 上校准，最后样本外验。
