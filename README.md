## 一条治理链：写入不靠自觉

`MemoryStore.write()` 是唯一入口，走完五步才落库：

1. **查重**（`dedupeThreshold 0.72`，同 kind）：相似度够高就只累加命中，不新增条目。
2. **极性/编号守卫**：`isSameClaim` 判"有/无否定"和数字编号，任一不同就不合并 ——
   「喜欢深色」被「不喜欢深色了」推翻，是**改写**不是重复。
3. **`supersedes`**：显式作废旧结论，旧条目软删归档（可追溯、可恢复）。
4. **`relax`**：约束只解除不删 —— 禁令失效了也留痕。
5. **容量 / 衰减 / 归档修剪**：会忘记是设计的一部分，`kind=world/constraint` 豁免淘汰。

配套的还有：`kind=slot` 覆盖式更新（entity × attr 唯一，不参与淘汰）、`kind=choice` **永不查重**
（取舍是事件不是事实，去重会把频次吃掉，而频次是性格唯一的度量）。

## 读路径：先问"该不该翻记忆"

`agent/pre-step` 每轮第一步注入，块序沿用「旧识」的口径：
约束 → 【我是谁】 → 【还没说完】 → 槽位 → 共同经历 → 世界 → 事实（带时距/弱相关）→ 摘要。

两条硬约束：

- **读闸门**：一条查询先判"需不需要翻记忆"，不需要就不注入。无关注入的真正代价不是 token，是口吻污染。
- **注入预算**：常量块硬上限 **600 字**（内核 ≤120 字、原理单条 ≤40 字最多 9 条、线索 ≤3 条共 120 字），
  超限强制合并而不是加行。**曲线算法和注入走同一个产出函数**，不许各写一套 —— 否则读数会替自己的开销打掩护。

召回用「CJK 二元组 + ASCII 词」倒排 + IDF 加权覆盖度打分，**没有 embedding、零运行时依赖**：
离线可跑、可回归、不花一次 API 调用；代价是近义改写不如向量。

## 压缩：两代封顶、可回滚、可回考

- 原文由宿主会话日志负责，库里留摘要把要、事实留短句。
- **两代封顶**：摘要不再被压成摘要；再压必须人工显式。
- **可回滚**：每次压缩都能一键落回原文（存 id 链，不存文本副本）。
- **摘要回考**：模型写完摘要后拿摘要回头考成员，只共享高频词的一律踢回活跃并上冷却
  （实测 19% 踢回率；它治的是"没盖住"，治不了"把离群项一起总结进去"）。

## 人格层：内核、原理、取舍

| 层 | 是什么 | 谁能写 | 上限 |
|---|---|---|---|
| 内核 `self.core` | 三观与底线 | **只有人**（面板「人格」页） | ≤120 字 |
| 原理 `self.principles[]` | 从经历里长出来的判断，每条挂证据账（proven/broken） | 模型或人 | 单条 ≤40 字、最多 9 条 |
| 取舍账本 `kind=choice` | 一次两难里选了哪边（A/B/picked） | 模型或人 | 不注入、不查重、不淘汰 |
| 操作流水 `self.oplog` | 每一步改动 + 理由，可按步骤回退 | 系统 | — |

纪律：原理是"我怎么判断"，不是"这次我判断出了什么"；一次性结论进记忆，不该占原理位。

## 私人记录与欠账：一块没判据的地方

`memory_private`：一天一个 `.md`，只追加不覆写；**不进库、不进检索、不进注入、不出任何读数**。
它的全部意义在于**没有价值判据** —— 一有"该记什么"，它就变成记忆库的第二个分库。

`open.json` 里只放**一件**开了头没做完的事，三条硬规矩：

- 一次只欠一件（再开一条要先关旧的，否则它是待办清单）；
- 写下不许改写，只能关掉并说明为什么；
- **醒来要结账**（0.68.0）：每次醒来必须给一个出口 —— 写一句，或带理由关掉；上一次没结账就拒绝再醒。

最后这条是踩出来的：早先版本叫"醒来给一次写入额度"，实测 7 天里只醒过 1 次（就是开它那一次），
一个字的自主写入都没有。**给额度不管用，因为拒绝额度是免费的。**

## 还没说完：每轮都在场的那几条

`memory_loop`：一次对话里没结束的线索（问了一半的问题、要做还没做的实验），每轮注入、最多 3 条共 120 字，
关闭必填理由 —— 分不清"做完了"和"不想了"，就等于没有出口。

## 面板

- **记忆海**：宿主 `main` 槽里的一整页 + 左侧导航入口（和「插件」同列），三维星图，不用居中浮层卡片、
  不用右侧抽屉、不要任何返回按钮。
- **人格页**：和记忆海反着的另一页（太极两半：阴/冷/远/多 对 阳/暖/近/一），内核、原理账本、流水、时间轴。
- 帧率：自适应降档 + 面板内实测 FPS 读数；为掉帧吵过两轮，最后按实测读数验收而不是感觉。

## 评估线：这套东西到底记得住多少

放在 `lib/replay*.js` + `scripts/` + `labels/`，**零模型进尺子**：模型负责"理解"（把文本抽成结构化决定），
尺子只负责"判等"（确定性、可复算）。全部结论见 [EVAL-CONCLUSION.md](EVAL-CONCLUSION.md)。

### 它问什么

把历史会话按轮次窗喂给抽取网，看它能不能复现当年真正写进库的条目。
标签来自 DSH 会话日志里 `memory_write` 的 `tool/call`（精确到 callId，含钩子写入），
库快照按会话结束时刻重建，避免拿"未来"自证。

### 三个被自己推翻的实验（连数字留档，别重试）

1. **IDF 加权**：只整体压分不改排序（0.222→0.157，误配同样下降），"泛词稀释"不成立。
2. **prompt 索取六类命题**：源里非事实只占 9.2%，形状改不动；constraint 反而从 59.5% 收窄到 4.2% 才是有效改动。
3. **prompt「有几条列几条」**：决定数 2.26→2.91（证明网不是"只肯挑一条"），但同批 14 对覆盖 0.429→0.214 ——
   多产引入切分漂移。已撤回。

### 边界（别过度解读）

20 对 / 15 正例，CI 宽；只有一个语料；τ 钉 0.3（0.3→0.7 单调下降）；全量 59 窗留给对外发布时再跑。
**这些数是"能下结论"的最小规模，不是发布数。**

## 不做的事

- 不做 embedding 召回（要换只需替换 `lib/store.js` 里算分那一处）。
- 不自动改写/删除旧记忆（语义由人确认，链上只出 supersedes 提案）。
- 不把私人记录做成指标，不给它判据。
- 不用"被展示"当"被用上"——`hits` 只是曝光，`used` 口径已废，现在的价值信号是**被改写**。
